# Estado da entrega

Este pacote contém o código Flutter do MVP MotoGest e um workflow GitHub Actions para gerar o APK Android.

O ambiente de preparação não tem Flutter/Dart instalados, por isso o APK não foi compilado nem testado nesta sessão. O GitHub Actions cria os ficheiros Android, instala as dependências, executa análise/testes e compila o APK. Corrija eventuais erros reportados pelo workflow antes de distribuir o APK.
